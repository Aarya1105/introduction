# 🌸 Anime Girl Portfolio — Aarya.exe

An interactive **Anime Character Portfolio Website** where a cute anime girl represents my digital identity and developer journey.

This project combines storytelling, animation, and modern web development to create an immersive scrolling experience.

---

## ✨ Concept

Instead of a traditional portfolio, an anime character acts as my virtual avatar.

**Character Profile**

* Name: **Aarya.exe**
* Class: Developer
* Mission: Build Future Web
